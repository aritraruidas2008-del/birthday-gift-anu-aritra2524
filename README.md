# Anu's Birthday Website

## GitHub Pages publishing
1. Create a GitHub repository.
2. Upload all files from this ZIP directly into the repository's main/root folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
5. Wait for GitHub Pages to publish the website.

Photos are beside `index.html`; there is no photos folder.

Optional background music: add your own audio file named `romantic.mp3` beside `index.html`.
